CR Paste · Chat & Macro Lines

Copy one line into chat or a macro editor, using Ctrl+V or touch buttons.

Paste into chat

Client update 1.0.12 includes crpaste and loads it automatically. Copy your text, return to the game, open the chat input and press Ctrl+V. Release the keys and let the helper type the line. It leaves the text for you to review and does not press Enter.

On a touch device, use the CR Paste panel’s Paste chat in 3s button, then select the chat input before the countdown ends.

Paste a macro command line

Copy one command line. In the game, open the macro’s command-line editor. Clear existing text if you want to replace it, then press Paste macro line in 3s in the CR Paste panel and select the destination field. The helper types the copied line; review and save it yourself.

Repeat for each macro line. Paste enters at the current position; it does not replace the whole macro or fill all six lines at once.

/ja "Max Potion" <p1>

For a keyboard shortcut in the macro editor, run /crpaste macro, open the line editor and press Ctrl+V within 20 seconds. This arms one macro-line paste.

Commands and cancellation

CommandUse
/addon load crpasteLoad if needed.
/addon reload crpasteReload installed code.
/crpaste showShow the touch panel.
/crpaste hideHide the panel; Ctrl+V remains available.
/crpaste macroArm the next Ctrl+V for a macro line.
/crpaste cancelCancel a queued or active paste.

Escape cancels an active paste. Switching away from the game cancels it too. Copy one line of up to 240 characters; ordinary English letters and punctuation are supported. Multiple lines, control characters and unsupported characters are rejected.

PC and ROG

The player confirmed Ctrl+V in chat and the macro-line touch button on H. The same addon is delivered to the ROG through the launcher; a receiving-device check remains part of the beta.

Close the game to install the launcher update, then reopen it. No Map or other server restart is needed.
