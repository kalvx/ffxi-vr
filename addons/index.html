Current Reality client reference

Addon Command Compendium.

Search the commands included with the Current Reality Ashita 4 client. Commands are entered in the in-game chat box. Addons and plugins can also be enabled or disabled from Launcher Settings before Play.

⌕
⚙

Ashita management

Load, unload, or reload a bundled addon or plugin during the current session.

/addon load <name>Load an addon, such as xicamera or boussole.
/addon unload <name>Unload an addon for this session.
/addon reload <name>Reload an addon after changing its configuration.
/load <plugin>Load an Ashita plugin.
/unload <plugin>Unload an Ashita plugin.
◉

XICamera

Adjust normal and battle camera distance, rotation range, and panning speed.

/cam distance 9Set normal camera distance. Alias: /cam d 9.
/cam battle 12Set battle camera distance. Alias: /cam b 12.
/cam brange 4Set battle rotation range from 0–100. Alias: /cam br.
/cam battlelock onLock or unlock the battle range governor. Alias: /cam bl.
/cam hspeed 3Set horizontal panning speed. Alias: /cam hs.
/cam vspeed 10.7Set vertical panning speed. Alias: /cam vs.
/cam incrIncrease normal distance. Aliases: /cam in.
/cam decrDecrease normal distance. Alias: /cam de.
/cam bincrIncrease battle distance. Alias: /cam bin.
/cam bdecrDecrease battle distance. Alias: /cam bde.
/cam saveOnIncrementToggle saving when incrementing or decrementing. Alias: /cam soi.
/cam autoCalcVertSpeedToggle automatic vertical-speed calculation. Alias: /cam acv.
/cam statusShow current camera settings. Alias: /cam s.
/cam helpShow XICamera help. Alias: /cam h.
⌖

Boussole

Control the enhanced map, minimap, markers, and generated floor information.

/boussoleToggle the Boussole interface.
/boussole showShow the interface.
/boussole hideHide the interface.
/boussole minimapToggle minimap mode.
/boussole genfloorsRegenerate the zone-floor data file.
⇄

XIPivot and Remapster

Inspect and manage non-destructive DAT overlays. Remapster is the default Current Reality map overlay.

/pivotOpen the XIPivot configuration interface.
/pivot dumpWrite the current overlay list and cache settings to the Pivot log.
/pivot query <DAT path>Identify which overlay supplies a particular file.
/pivot query allWrite a report containing all active redirects.
/pivot helpShow Pivot command help.
▥

FPS

Current Reality loads the FPS addon automatically and binds the standard FPS control.

/fpsUse the addon’s FPS command interface.
F12Current Reality startup binding for the FPS command.
/addon reload fpsReload FPS after changing its saved configuration.
▣

Screenshot

Capture screenshots with optional interface hiding.

/screenshot hideCapture while hiding supported interface elements.
Print ScreenCurrent Reality startup binding for /screenshot hide.
/load screenshotLoad the Screenshot plugin.
◈

Toon

Toggle the bundled Toon shader plugin for the current session.

/load toonEnable Toon shading.
/unload toonDisable Toon shading.
▦

Minimap

Control the classic Minimap plugin when Boussole is not preferred.

/load minimapEnable the classic Minimap.
/unload minimapRemove it for this session.
↔

Distance

Show range information for the selected target.

/addon load distanceEnable target-distance information.
/addon unload distanceDisable it for this session.
/addon reload distanceReload its saved configuration.
✥

Move

Reposition supported interface elements and addon windows.

/addon load moveEnable Move.
/addon unload moveDisable Move for this session.
/addon reload moveReload after configuration changes.
◷

Timestamp

Add time markers to chat-log messages.

/addon load timestampEnable chat timestamps.
/addon unload timestampHide timestamps for this session.
/addon reload timestampReload its saved settings.
♟

TParty

Display enhanced party and alliance status information.

/addon load tpartyEnable the enhanced party display.
/addon unload tpartyReturn to the normal party display.
/addon reload tpartyReload its saved settings.
⌨

Current Reality keybinds

Useful bindings installed by the bundled Ashita startup script.

InsertOpen the Ashita interface.
Ctrl + VPaste clipboard text into FFXI.
F11Run the ambient-light command.
Ctrl + F1…F6Target alliance slots 10–15.
Alt + F1…F6Target alliance slots 20–25.

Persistent changes: Use Current Reality Launcher Settings when you want a feature choice saved for future launches. Direct load and unload commands affect only the active game session unless the addon saves its own settings.
