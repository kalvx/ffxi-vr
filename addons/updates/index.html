Test release · October 8, 2026

Current Reality 0.1.6

For players with Current Reality 0.1.5 already installed. This patch restores the updated PlayOnline files and adds launcher updates.

Download patch installer ↓Download checksums

Windows · Approximately 20 MB · Startup testing is still in progress. This is a patch, not a full installation for a new PC.

Apply this patch

  1. Close the game and Current Reality launcher.
  2. Download and run the patch installer. Select your existing Current Reality folder if asked.
  3. Open Current Reality. Home checks your managed files; use Update required if repairs are needed, then Play once verification passes.

What changes

  • Restores the verified updated PlayOnline DLL pair.
  • Adds update checks beside Play and repairs missing or changed managed files.
  • Backs up replaced files and preserves account settings, macros, server address, and personal configuration.

This patch addresses changed client files. Successful startup on the Ally is still being tested; it is not yet a confirmed fix for every launch failure.

Future updates

The launcher downloads the published patch, verifies its files, applies it with backups, and opens again. Updates must finish before Play. You will not need a full reinstall for these managed-file updates.
