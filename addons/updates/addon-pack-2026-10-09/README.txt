CURRENT REALITY ADDON PATCH - October 9, 2026

Includes CRCrafting 0.2.0, CRHotSwap 1.2.0 and CRMM 1.2.1, with their helper files and macro scripts.
Close the game and launcher. Run the patch installer and select your existing Current Reality folder (the folder containing Runtime).
Alternatively, extract the ZIP into that Current Reality folder, merging Runtime. Back up existing addon files first if using the ZIP.
For a standalone Ashita v4 install, copy Runtime/addons contents into your addons folder and Runtime/scripts contents into your scripts folder.

In game:
/addon load crcrafting
/addon load crhotswap
/addon load crmm

These are manual loads; startup scripts, accounts and personal settings are unchanged.
CRCrafting repeats your last synthesis recipe. CRHotSwap provides equipment sets. CRMM is the Summoner combo helper.
CRMM requires the matching Current Reality server support already installed on the host; the patch installs client files only.
Packaging has been verified. Loading on the receiving PC still needs an in-game check.
